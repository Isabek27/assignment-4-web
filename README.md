## About The Project
This is a simple two-page web project for Astana IT University (AITU) built with HTML5, Bootstrap 5, and custom CSS.

## Pages Overview
* **index.html** — AITU Student Support ticket form with HTML5 validation (`required`, `email`, `maxlength`)[cite: 1].
* **register.html** — Student account registration form with responsive Bootstrap grid, password fields, radio buttons, select dropdown, and checkboxes[cite: 2].

## Technologies Used
* HTML5
* Bootstrap 5 (CDN)
* Custom CSS (`css/style.css`)

## Project Structure
* `index.html` — Support form page[cite: 1]
* `register.html` — Registration page[cite: 2]
* `css/style.css` — Custom styles[cite: 3]
